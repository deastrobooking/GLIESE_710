# Granular Oscillator

## MVP Scope

`GranularOsc` is a real-time safe oscillator core with immutable fixed-size sample assets and a preallocated grain pool. Each granular panel accepts WAV, AIFF, FLAC, and OGG files from its chooser or by drag-and-drop, decodes and resamples them on a background worker, previews the resulting waveform, and hands the completed asset to all voices at a render-block boundary. It does not yet include live input capture, region markers, scenes, preset sample dependencies, or sample-browser infrastructure.

The identity of this first pass is:

```text
sample source -> preallocated stereo grain cloud -> optional physical body -> synth voice mix
```

## Engine

There are eight independent `GranularOsc` instances per voice. Each instance uses:

| Resource | Purpose |
|---|---|
| Shared immutable stereo `SampleData[65536]` | Fixed left/right source asset, generated by default or decoded/resampled off-thread |
| `Grain[96]` | Preallocated active grain pool |
| `ModalMode[32]` | Optional physical body/modal resonator bank |
| Trigger clock | Free-cloud, burst, or audio-rate grain spawning |
| Deterministic RNG | Repeatable per-note spray, pan, pitch jitter, and reverse decisions |

The fixed source representation keeps grain reads allocation-free. Loading creates one shared immutable asset per slot instead of duplicating it across every voice. The engine queues the pointer under a short message-thread lock and the audio thread claims it with a non-blocking try-lock at the next render-block boundary.

## Sample Loading

Use **LOAD SAMPLE** in a granular panel or drop a supported audio file directly onto its waveform. Decode, stereo-to-mono conversion, and conversion into the 65,536-sample granular table happen on a single background worker owned by that panel. Files are capped at the first 120 seconds during decode to bound temporary memory use. A successful load updates the panel waveform and affects that granular slot on all voices.

Each slot also exposes **START**, **END**, **SLICES**, **SELECT**, **ROOT**, and **AUTO** controls. Start/end constrain grain spawning to a normalized source region. With AUTO off, slices divide that region evenly. With AUTO on, the background loader's energy-onset analysis supplies up to 32 transient boundaries instead. Selection chooses the active equal or transient division. ROOT identifies the imported sample's MIDI reference pitch and compensates playback accordingly. The waveform shades excluded audio, draws the active boundaries, and highlights the selected slice.

Loaded sample assets are embedded in plugin and user-preset state as a versioned binary payload. The current payload contains normalized left and right 65,536-sample tables plus transient metadata, so presets are portable and preserve stereo information. Restoration remains backward compatible with the earlier mono payload by copying its channel into both sides. It validates the header, version, size, sample bounds, and ordered marker data before using the normal immutable block-boundary handoff.

## Live Input Capture

The plugin exposes an optional mono or stereo input bus. When enabled by the host, incoming audio is written into a preallocated 30-second stereo circular recorder. The audio callback uses a try-lock and skips recorder writes if a UI capture is in progress, so it never waits for the message thread.

Each granular slot has a **CAPTURE** button. It freezes the most recent eight seconds, converts the snapshot into a stereo granular asset, runs transient analysis, updates the waveform, hands the immutable result to every voice, and embeds it in state. If the host input bus is disabled or has not received audio, the button reports **NO INPUT**.

## Sample Library

Each granular slot includes a library selector and **SCAN** button. The selector recursively lists supported audio files from:

```text
Music/GLIESE_710/Samples
```

The folder is created on first use. Choosing an entry sends it through the same background decode, transient analysis, immutable handoff, waveform, and preset-embedding path as drag-and-drop. SCAN refreshes the list after files are added or reorganized.

## Granular Scenes

Each slot has four named scene positions. Selecting a scene recalls its region start/end, equal slice count, selected slice, root note, and transient AUTO state. **SAVE** writes the current values into the selected scene. Scene selection and all four snapshots are APVTS parameters, so they survive plugin state, automation-compatible preset serialization, and user preset exchange.

## Trigger Modes

### Free Cloud

Continuously spawns grains from the density clock. Best for pads, drones, smears, and evolving clouds.

### Burst

Starts a finite grain burst on note-on. Density controls how fast the burst emits.

### Audio Rate

Ties the grain trigger rate to note frequency and density, pushing the grain stream toward oscillator-like behavior.

## Physical Body

The physical body section is optional and defaults to bypass:

```text
body type = Off
body mix  = 0
```

When enabled, the stereo grain cloud excites a fixed modal resonator bank. This keeps the synth granular, while letting grains ring through modeled bodies such as glass, metal, wood, plates, strings, drums, pipes, and alien alloys.

The implementation is a practical modal-resonator MVP: a bank of preallocated band-pass modes with body-specific frequency ratios, damping, brightness tilt, inharmonic stretch, excitation gain, and stereo spread. It is not a finite-difference or circuit-accurate physical simulation.
